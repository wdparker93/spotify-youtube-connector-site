How It Works

Up and running in minutes

Three steps from install to your first synced video.

1

Install the Extension

Add Spotify Visualizer to Chrome from the Web Store, then connect your Spotify account when prompted. No Premium subscription required.

2

Add a YouTube API Key

Create a free API key at Google Cloud Console in about two minutes. Paste it into the extension settings — one time, and you're done.

3

Turn On Sync & Play

Flip the sync toggle in the popup, start a song in Spotify, and watch the YouTube video appear automatically — perfectly timed.
